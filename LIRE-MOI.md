# La roue des ombres — Squadir

Ouvrir **index.html** dans Chrome, Edge ou Firefox. Le site fonctionne directement, sans installation et sans connexion Internet.

- Sélectionner un cadeau à gauche, puis cliquer sur **INVOQUER LE SORT** (ou appuyer sur Espace).
- Les trois pass, les deux codes et Amazon ont chacun leur liste issue du tableau fourni. Amazon prévoit deux tirages pour les deux cartes.
- Le bouton **Modifier les participants** change uniquement la liste de la roue sélectionnée : un pseudo par ligne.
- Dans les réglages, **Une victoire par personne** permet d’exclure les gagnants précédents de toutes les roues. Cette option est désactivée au départ.
- Le grimoire conserve les résultats. **Exporter** télécharge un CSV compatible avec Excel.
- Les boutons en haut à droite contrôlent le son, le plein écran et les réglages.

Les listes et l’historique sont enregistrés localement dans le navigateur utilisé. Pour conserver une copie des résultats, utiliser l’export avant de réinitialiser la session ou d’effacer les données du navigateur.

Les fichiers doivent rester ensemble : `index.html`, `style.css`, `app.js`, `data.js` et le dossier `assets`.
